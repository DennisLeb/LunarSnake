# Lunar Snake

Lunar Snake is a basic snake clone built using raylib.

<img width="722" height="572" alt="grafik" src="https://github.com/user-attachments/assets/3d8b6b43-c7de-4aa8-ab47-6bb91604ed50" />


## Features

It includes the classic snake game loop of collecting "snacks", in this case tiny green aliens, to grow your snake and increase your score.

There are also some menu interfaces, which were all drawn by me and some animations to spice things up.

<img width="722" height="572" alt="grafik" src="https://github.com/user-attachments/assets/baa53305-f070-4151-a052-dfdfd1156a98" />


## Controls

* To move around use the 'WASD' keys or the arrow keys.
* Press 'R' to restart.
* Optionally turn game speed up or down using the ',' and '.' keys.
* Press 'ESC' to pause and unpause.
